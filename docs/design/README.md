# Design snapshot

Verbatim copies of the original vboard UI (TanStack Start build, commit `861f513`), kept as the reference the Next.js rebuild was ported from. They are not compiled, linted, or formatted.

- `styles.css` — the original token and primitive stylesheet
- `components/` — Nav, Footer, PostCard, EventCalendar, UnderConstruction
- `pages/` — the original route components
- `components.json` — the original shadcn config (zinc, new-york)

The live equivalents are `src/app/globals.css`, `src/components/`, and `src/app/`. The spec that describes both is `docs/UI_UX_SPEC.md`.
